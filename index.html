    About this dApp

    The ticket sale is handled by a smart contract, so there is no middleman and every booking can be checked on Etherscan.

    Contract functions

    • buyTicket (write, payable) books a seat for the exact ticket price
    • withdrawFunds (write) lets only the organiser take out the money
    • getEventDetails (read) returns name, venue, date, price and seats
    • getTicket (read) returns the seat number of a wallet
    • getAttendees (read) returns all wallets that booked
